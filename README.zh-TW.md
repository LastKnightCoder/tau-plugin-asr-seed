# 豆包語音辨識

為 Tau 提供中英文語音辨識：既可以邊說邊即時轉成文字輸入，也可以將錄好的音訊轉換成附時間戳記的逐字稿。

## 開始使用

1. 前往[豆包語音控制台](https://console.volcengine.com/speech/new/)開通所需的服務，並在「API Key 管理」中建立 API Key：
   - **即時語音輸入**：開通「串流語音辨識 2.0」，並確認帳號對應的「計費資源」類型（「按時長」或「按並行數」）。
   - **錄音轉文字**：開通「錄音檔案辨識」的標準版或極速版（開通任一個即可）。
2. 在外掛中心安裝並啟用「豆包語音辨識」。
3. 進入本外掛詳情的「設定」，新增帳號，填寫 API Key、選擇對應的計費資源與辨識模型後儲存。
4. 在 Tau 的語音設定中選用這個帳號，就可以開始使用語音輸入或錄音轉文字。

## 常見問題

**錄音檔案辨識的標準版與極速版有什麼差別？** 標準版不限制錄音時長，但要求錄音存放在可公開存取的遠端儲存空間；極速版支援直接上傳錄音，單次最長 2 小時。兩者皆開通時，會優先使用標準版，不可用時自動改用極速版。

**支援哪些音訊格式？** 進行錄音轉文字時，MP3、WAV 與 Ogg Opus 會原樣交給豆包語音辨識；其他格式（例如手機錄音常見的 m4a）會由 Tau 自動轉為 Ogg Opus 後再辨識。

**錄音資料與辨識費用怎麼處理？** 錄音由 Tau 管理，音訊透過安全連線傳送至豆包語音服務，辨識費用計入你設定的帳號。外掛本身不會保存你的錄音或逐字稿。錄音存放在遠端儲存時，豆包語音會依網址讀取（轉出的副本也留在同一個儲存空間）；錄音存放在本機時則直接上傳辨識，不會額外上傳至其他地方。實際辨識效果取決於音訊清晰度與服務狀態。

## 小提醒

- 語音輸入與錄音轉文字會產生豆包語音服務費用，請留意控制台的計費方式與用量。
- API Key 相當於帳號憑證，請妥善保管，不要提供給他人，也不要出現在截圖或問題回饋裡。
