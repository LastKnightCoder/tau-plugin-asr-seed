# 豆包语音识别

为 Tau 提供中英文实时语音输入：说话时预览文字，停止后将识别结果交给输入框。聊天消息由你确认发送。

## 开始使用

1. 在支持语音识别插件的 Tau 中安装并启用本插件。
2. 在豆包语音控制台开通“流式语音识别 2.0”，取得 API Key，确认账号使用按时长或按并发资源。
3. 打开 Tau 的“语音输入”设置，填写 API Key 和计费资源，保存后点击“选用”。
4. 在输入框点击麦克风，允许麦克风权限，说完后点击停止。

需要桌面 0.59.5、Android/iOS 0.2.5 或之后支持相同接口的版本。录音由 Tau 管理，音频通过安全连接发送至豆包语音服务；识别费用归对应账号。插件不保存录音或识别正文，不把密钥放入 URL 或日志。

## 常见问题

- 账号错误：使用豆包语音控制台的 API Key，并确认开通的资源类型与所选计费方式一致。
- 输入变化：录音期间手动编辑了输入内容时，Tau 会保留转录结果供复制，避免覆盖新内容。
- 服务断开：检查网络和额度后重新录音。中断任务不会自动重放或切换其他账号。
- 手机不可录音：检查系统麦克风权限及 WebView 版本。

当前能力为中英文实时输入，不提供录音文件转录。
