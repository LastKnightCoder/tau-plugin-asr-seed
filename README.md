# 豆包语音识别

为 Tau 提供中英文语音识别：边说边出文字的语音输入，以及把录好的音频转成带时间的文字稿。

## 使用条件

安装并启用后，在本插件详情的「设置」中填写账号与识别模型，然后在应用语音设置中选用。麦克风输入入口的开放与账号配置独立，不会因安装插件自动出现。

接口要求桌面至少 0.60.2、Android/iOS 至少 0.2.9；满足版本号不代表入口已经开放。Windows 本轮不提供系统原生识别，豆包识别由本插件单独提供。

使用服务前，在豆包语音控制台取得 API Key，并开通要用的服务：

- 语音输入：开通“流式语音识别 2.0”，并确认账号的按时长或按并发资源类型。
- 录音转文字：开通“录音文件识别”的标准版或极速版，任一即可。标准版不限时长，但需要录音存在能公开访问的远程存储里；极速版直接上传录音，单次最长 2 小时。两个都开通时先用标准版，不可用时自动改用极速版。

账号配置通过插件设置表单填写，不要把密钥写入插件源码。

## 数据与费用

录音由 Tau 管理，音频通过安全连接发送至豆包语音服务，识别费用归对应账号。插件不保存录音或识别正文，不把密钥放入 URL 或日志。中断任务不会自动重放或切换其他账号。

录音转文字时，MP3、WAV、Ogg Opus 原样交给豆包语音，其他格式（如手机录音的 m4a）由 Tau 先转成 Ogg Opus。录音存在远程存储时，豆包语音按地址下载（转出的副本放进同一个存储）；录音存在本机时直接上传，不会为转文字上传到其他地方。实际识别质量取决于音频和服务状态。
