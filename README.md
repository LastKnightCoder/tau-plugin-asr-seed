# 豆包语音识别

为 Tau 提供中英文流式语音识别能力，支持临时文字修订、停止后的完整结果和任务取消。

## 使用条件

当前 Tau 尚未开放语音输入与账号配置入口。安装并启用本插件不会出现麦克风按钮或配置页面，请等待提供这些入口的客户端版本后再使用。

接口要求桌面至少 0.59.5、Android/iOS 至少 0.2.7；满足版本号不代表入口已经开放。Windows 本轮不提供系统原生识别，豆包识别由本插件单独提供。

使用服务前，需要在豆包语音控制台开通“流式语音识别 2.0”，取得 API Key，并确认账号的按时长或按并发资源类型。账号配置应通过 Tau 将来提供的表单填写，不要把密钥写入插件源码。

## 数据与费用

录音由 Tau 管理，音频通过安全连接发送至豆包语音服务，识别费用归对应账号。插件不保存录音或识别正文，不把密钥放入 URL 或日志。中断任务不会自动重放或切换其他账号。

本插件提供流式识别，不提供录音文件转录。实际识别质量取决于音频和服务状态。
