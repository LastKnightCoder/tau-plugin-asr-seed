# 豆包语音识别

为 Tau 提供中英文流式语音识别能力，支持临时文字修订、停止后的完整结果和任务取消。

## 使用条件

安装并启用后，在本插件详情的「设置」中填写账号与识别模型，然后在应用语音设置中选用。麦克风输入入口的开放与账号配置独立，不会因安装插件自动出现。

接口要求桌面至少 0.60.2、Android/iOS 至少 0.2.9；满足版本号不代表入口已经开放。Windows 本轮不提供系统原生识别，豆包识别由本插件单独提供。

使用服务前，需要在豆包语音控制台开通“流式语音识别 2.0”，取得 API Key，并确认账号的按时长或按并发资源类型。账号配置通过插件设置表单填写，不要把密钥写入插件源码。

## 数据与费用

录音由 Tau 管理，音频通过安全连接发送至豆包语音服务，识别费用归对应账号。插件不保存录音或识别正文，不把密钥放入 URL 或日志。中断任务不会自动重放或切换其他账号。

本插件提供流式识别，不提供录音文件转录。实际识别质量取决于音频和服务状态。
