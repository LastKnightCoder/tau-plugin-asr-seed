# 豆包语音识别

为 Tau 提供中英文语音识别：既可以边说边实时转成文字输入，也可以把录好的音频转成带时间戳的文字稿。

## 开始使用

1. 前往[豆包语音控制台](https://console.volcengine.com/speech/new/)开通需要的服务，并在「API Key 管理」中创建 API Key：
   - **实时语音输入**：开通「流式语音识别 2.0」，并确认账号对应的「计费资源」类型（「按时长」或「按并发」）。
   - **录音转文字**：开通「录音文件识别」的标准版或极速版（开通任意一个即可）。
2. 在插件中心安装并启用「豆包语音识别」。
3. 进入本插件详情的「设置」，添加账号，填写 API Key、选择对应的计费资源与识别模型后保存。
4. 在 Tau 的语音设置中选择这个账号，就可以开始使用语音输入或录音转文字了。

## 常见问题

**录音文件识别的标准版和极速版有什么区别？** 标准版不限制录音时长，但要求录音存放在可公开访问的远程存储中；极速版支持直接上传录音，单次最长 2 小时。两个都开通时，会优先使用标准版，不可用时自动改用极速版。

**支持哪些音频格式？** 录音转文字时，MP3、WAV 和 Ogg Opus 会原样交给豆包语音识别；其他格式（例如手机录音常见的 m4a）会由 Tau 自动转为 Ogg Opus 后再识别。

**录音数据和识别费用怎么处理？** 录音由 Tau 管理，音频通过安全连接发送至豆包语音服务，识别费用计入你配置的账号。插件本身不保存你的录音或文字稿。录音存在远程存储时，豆包语音按地址读取（转出的副本也留在同一存储中）；录音存在本机时直接上传识别，不会额外上传到其他地方。实际识别效果取决于音频清晰度与服务状态。

## 小提醒

- 语音输入与录音转文字会产生豆包语音服务费用，请留意控制台的计费方式和用量。
- API Key 相当于账号凭证，请妥善保管，不要发给别人，也不要出现在截图或问题反馈里。
